# CWT Type Specimen

Internal Milestone 01.1 specimen. This is not a public route and not a homepage design.

## Compact Wordmark

```text
CWT
```

Treatment: Archivo, uppercase, weight 800, neutral ink, no project accent.

## Full-Name Treatment

```text
CREATEWITHTIMI
```

Treatment: Archivo, uppercase, label scale, weight 800 or 700 depending on context, neutral ink.

## Display Statement

```text
WE BUILD WORLDS
AROUND STORIES
PEOPLE CARE ABOUT.
```

Treatment: Archivo Narrow, weight 700, very large, tight leading, controlled line breaks.

## System Labels

```text
INDEPENDENT CREATIVE-TECHNOLOGY STUDIO / 2026

CASE STUDY 001
```

Treatment: Archivo, uppercase, small label scale, weight 700. System tone comes from size, case, and restraint rather than a separate monospace family.

## Body Sample

CreateWithTimi transforms stories, brands and cultural IP into connected digital and physical experiences audiences can enter.

Treatment: Archivo, regular weight, comfortable editorial leading.

## Responsive Notes

The display scale is fluid and intended to stay dramatic from desktop through mobile. Future composed pages should control important line breaks in markup and layout rather than relying on arbitrary text wrapping.
